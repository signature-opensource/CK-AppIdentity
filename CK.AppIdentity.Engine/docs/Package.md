The engine of CK.AppIdentity: it generates the PartyComponentOptionDirectory, the options of each party component owner type
of the application (IPartyComponentOption<TOwner>, decorated with [FeatureOption] or [PartyClientOption]), ordered by their
topology attributes, with a factory per option. See https://github.com/signature-opensource/CK-AppIdentity/blob/stable/CK.AppIdentity/PartyComponentOptions/README.md.

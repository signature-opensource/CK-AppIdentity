# CK.Testing.AppIdentity

Assembles an ApplicationIdentityService without the engine, for the tests of the run time: `AppIdentityTestHelper`
registers the service, the feature drivers and the PartyComponentDirectory computed from the component types by the
engine's own analysis (PartyComponentAnalysis).

See the [README](https://github.com/signature-opensource/CK-AppIdentity/blob/stable/CK.Testing.AppIdentity/README.md).
